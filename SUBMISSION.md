## Title

## Tagline

## Description
Bill Floor Buddy is a tiny local web app that helps you hit a hard cash deadline. You set a cash goal (default $2300), how much you’ve already saved, and a deadline (default Nov 30, 2026). Then you list the bills that floor has to cover. The app instantly shows days left, remaining gap, and daily needed — so the scary lump sum becomes a number you can act on today.

Who it’s for: anyone racing a real bill floor (built around Bradley Conger’s Nov 30 cash target).

What I learned: using the Devpost Learn Skill Pack to scope → PRD → spec before coding kept this to one honest end-to-end loop instead of a bloated budget app. localStorage + a zero-dependency Node static server was enough to ship a demoable proof of concept.
