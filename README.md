# Bill Floor Buddy

Tiny local web app that turns a cash deadline into two numbers you can act on: **remaining gap** and **daily needed**.

Built for Devpost **Build With AI: Basics** with the [Learn Skill Pack](https://github.com/challengepost/learn-ai-basics) (`scope.md` / `prd.md` / `spec.md` live in [`devpost/`](./devpost/)).

## Who it's for

Anyone racing a hard cash floor — defaulted to Bradley’s **$2300 by Nov 30, 2026** bill deadline.

## What it does

1. Set cash goal, amount saved, and deadline.
2. Add bills to a checklist (rent, utilities, food…).
3. Instantly see days left, remaining gap, and daily needed.
4. Data stays in your browser (`localStorage`) — no accounts, no paid APIs.

## Run (one line)

```bash
npm start
```

Then open **http://127.0.0.1:3847**

Requires Node.js 18+.
